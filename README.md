# marxx private VideoCLIP repository

This is a private hosting of the VideoCLIP codebase for marxx.

# Description

This repository is a fork/hosting of the original [VideoCLIP-XL] model, intended for internal use by marxx. It is used to support long description understanding for video CLIP models.
